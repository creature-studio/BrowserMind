Install a provider plugin (no code, no rebuild)

Paste a manifest with a selector pack. The extension registers the content script for the new pattern (granting host access when Chrome asks) and the runtime registers the same plugin as a worker provider.

Sandboxed plugin host (Phase 4)

Run an untrusted third-party adapter in the CSP sandbox. It receives a tunnelled DOM driver for the selected tab and is exposed to the runtime as a worker with location: "sandbox".
